# AI 视频 Prompt 模板

只读取和使用当前任务对应的部分。模板是检查框架，不要求把每个字段都塞进最终 Prompt。

## 导演简报

```text
视频目的：
目标观众与发布平台：
画幅与总时长：
生成工具与模式：
主角及固定设定：
故事发生地与时间：
触发事件：
情绪起点 → 变化过程 → 情绪终点：
必须出现的动作或画面：
参考图与固定风格：
必须避免的问题：
素材权利或发布限制：
本轮验收标准：
```

## 智能分镜

```text
请把下面的创作要求写成一段适合智能分镜模式的完整导演描述，不按时间段拆开。

先交代视频目的、时长、主角、场景和整体风格；用触发事件推动动作和情绪；固定人物外貌、服装、道具和主色。短视频默认在结束前约 1 秒完成主要故事，最后自然收尾；如果用户明确要求循环或硬切，则按创作意图处理。最后集中写负面约束。

创作要求：
[主题与目的]
[角色锚点]
[场景与视觉方向]
[故事和情绪线]
[参考图]
[必须保留]
[必须避免]
```

## 自定义分镜

```text
请按时间段输出自定义分镜。每段只写该时间真正需要生成的画面，并包含：
- 时间范围
- 主体、动作与细微情绪
- 景别与运镜
- 光线、色调与环境
- 与上一镜头的连续关系
- 本镜头必须保持一致的内容

统一约束放在最后：角色锚点、参考图约束、道具外形、真实物理运动、负面约束。字幕、旁白、音乐和音效由后期单独处理。

总时长：[填写]
故事线：[填写]
情绪线：[填写]
角色锚点：[填写]
视觉方向：[填写]
```

## 原创角色图生视频

```text
参考图中的人物就是最终角色。先提取并固定头部与脸型、五官、身体比例、服装饰品、主色和标志性细节，再写动作、情绪、场景与镜头。

新角度只改变镜头和姿势，不重新设计角色。动作应符合角色体型，前后镜头必须被识别为同一个人物。禁止变脸、换衣、增肢、颜色漂移、比例变化和画风跳变。

故事：[填写]
时长：[填写]
动作与情绪：[填写]
场景与光线：[填写]
```

## 成片问题诊断

```text
这是第一版成片/截图和原 Prompt。不要直接整段重写：
1. 标出已经达到目标、必须保留的部分；
2. 定位问题时间段或镜头；
3. 判断属于故事、角色、动作、情绪、运镜、节奏、色调、声音、Prompt 冲突还是工具限制；
4. 指出最可能导致问题的原指令；
5. 只修改必要部分；
6. 输出修改后的完整可复制 Prompt；
7. 列出修改点和本轮验收标准。
```
