# AI 视频导演式工作流

把一句零散想法推进成一条能生成、能检查、能局部修改、能交付的视频方案。先做创作决策，再写 Prompt；工具服务于任务，不为展示工具数量而堆叠流程。

## 工作原则

1. 先明确观众最终应该看懂什么、感受到什么，再决定画面和工具。
2. 把角色设计、画面生成、声音、剪辑和发布拆成不同任务处理。
3. 对已经确定的角色使用“角色锚点”，不要在每轮 Prompt 中重新设计人物。
4. 第一版有问题时保留已经成功的部分，只修改导致失败的镜头或指令。
5. 不把未观看的成片描述成已达标，也不把平台数据或效果提升写成未经验证的事实。
6. 保存原始想法、参考图、Prompt、生成结果和每轮修改记录，以便比较与复盘。

## 0. 建立创作与安全边界

开始前确认或明确标注假设：

- 视频目的、目标观众、发布平台、画幅、时长和交付形态；
- 生成工具、输入模式、可用额度和本轮试错预算；
- 人物、肖像、品牌、参考图、字体、音乐和素材的使用权；
- 平台关于 AI 标注、水印、版权和内容发布的要求；
- 不允许出现的内容、误导风险和可能影响真实人物的表达。

无法确认素材权利时，不默认可以商用或公开；改用用户自有、已授权或可替代素材。涉及真实人物、品牌或敏感主题时，提高审核强度。

先写 3–6 条可观察的验收标准，例如：角色不变脸、主要情绪在第 8 秒前完成、最后 1 秒自然收尾、画面中不出现乱码文字。

## 1. 补齐导演简报

从用户的原始想法中整理以下信息：

- **传播目的**：让观众记住、理解或感受到什么；
- **故事线**：人物处境、触发事件、主要动作和结尾；
- **情绪线**：情绪起点、变化原因、中间过渡和情绪终点；
- **角色锚点**：脸型、眼睛、发型、体型、服装、饰品、主色和标志性细节；
- **视觉方向**：场景、时间、光线、色调、质感、景别和运镜；
- **制作限制**：工具、模式、时长、参考图、比例、预算和发布要求。

信息不足时先列出少量合理假设。只有会明显改变故事、角色或发布风险的缺口才需要暂停询问。

## 2. 选择生成路线

- **文生视频**：角色尚未锁定、重点是概念或单一场景时使用。
- **图生视频**：已经有角色或产品参考图，需要优先保持一致性时使用。
- **智能分镜**：工具自行拆镜，适合一段完整、连续的导演描述。
- **自定义分镜**：需要按秒控制动作、情绪、景别和衔接时使用。
- **多工具协作**：仅在任务确有分工时使用，例如角色设计、视频生成和后期分别处理。

不要把按秒分镜直接塞进智能分镜，也不要在图生视频 Prompt 中重新发明参考图里的角色。

## 3. 构建可执行 Prompt

按下面顺序组织内容，并删除重复形容词：

1. 视频目的、时长和整体风格；
2. 主角与必须固定的角色锚点；
3. 场景、时间、光线和主色；
4. 故事触发事件与主要动作；
5. 情绪的可见变化，包括眼神、呼吸、停顿和微动作；
6. 景别、运镜、镜头衔接和物理连续性；
7. 收尾：短视频默认在结束前约 1 秒完成主要故事，最后只保留稳定镜头或轻微环境变化；循环视频、故意硬切等明确创作意图可以例外；
8. 负面约束：变脸、换装、增肢、比例漂移、颜色突变、道具变形、画风跳变、文字乱码和突然截断。

需要可复制 Prompt 时读取 [prompt-templates.md](references/prompt-templates.md)，只选与当前模式有关的模板。

## 4. 交付生成包

第一轮交付至少包含：

- 一句话创作目标；
- 目标工具、模式、画幅和时长；
- 可直接复制的最终 Prompt；
- 角色锚点与参考素材清单；
- 负面约束；
- 字幕、旁白、BGM、音效、封面和剪辑的独立说明；
- 本轮验收标准和未确认假设。

如果给出多个版本，说明每个版本的取舍，不要只给一组意义相同的改写。

## 5. 诊断第一版并局部迭代

收到成片、截图或用户反馈后：

1. 标出已经达到目标、必须保留的部分；
2. 定位问题发生的时间段或镜头；
3. 分类原因：故事、角色一致性、动作、情绪、运镜、节奏、色调、声音、Prompt 冲突或工具限制；
4. 找出最可能导致问题的具体指令；
5. 只修改必要部分，重新输出完整可复制 Prompt；
6. 对照同一组验收标准比较新旧结果；
7. 记录本轮修改点、结果和仍未解决的问题。

如果失败来自工具本身的能力边界，明确说明并提出换模式、换工具、拆镜头或转后期处理的方案，不无限堆叠 Prompt。

## 6. 发布前验收与留档

发布、交付或写入作品集前读取 [quality-safety-checklist.md](references/quality-safety-checklist.md)。重点检查故事可懂性、角色一致性、画面异常、声音版权、AI 标注、平台要求和证据留存。

最终留档：`原始想法 → 导演简报 → 参考素材 → Prompt V1 → 第一版 → 问题定位 → 局部修改 → 最终版 → 发布信息`。

只有观察过最终成片并完成相应检查，才可以写“已通过”；否则标记为“待验证”或“预计效果”。
